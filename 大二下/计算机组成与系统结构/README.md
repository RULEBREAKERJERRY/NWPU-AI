## 26 春考试回忆版

### 一、给你应用程序 $A$ 在多周期处理器 $P$ 上各种指令的 $CPI$ 和占比和多周期处理器 $P$ 的主频 $f$

1. 求应用程序 $A$ 在处理器 $P$ 上的平均 $CPI$
2. 给你应用程序 $A$ 在处理器 $P_{new}$ 上各种指令的 $CPI$，占比不变，主频 $f$ 变为原来的 1.5 倍。求处理器 $P_{new}$ 的平均 $CPI$；求处理器 $P$ 和 $P_{new}$ 哪一个性能更好
3. 处理器 $P$ 的访存指令速度加速 2 倍，分支指令速度加速 1.8 倍，利用 Amdahl 定律计算加速比
4. 内容忘了，比较简单

### 二、IEEE 754 单精度浮点数

1. 将 `-14.375` 转化为单精度浮点数，并用十六进制表示
2. 将十六进制单精度浮点数 `0xC1000000`，转化为十进制
3. 将前两问的两个浮点数计算浮点数加法，写出具体过程

### 三、单周期 CPU 分析题，给你单周期的简化数据通路（没有 IF 阶段）

1. 添加一条交换指令：`swap rs, rt`，画出数据通路，标出要添加的器件
2. 单周期计算 $CPI$ 和 $cycles$
3. 给你各种指令的 $CPI$ 和占比，多周期计算 $CPI$ 和 $cycles$
4. 不考虑各种冒险，流水线计算 $CPI$ 和 $cycles$

### 四、流水线 CPU 分析题，给你一段 Loop，执行 100 次。题目要求分析一次迭代。无分支预测和延迟槽，无任何前递和旁路

1. 绘制时空图，使用 $*$ 标注出冒险所在的位置和延迟的周期数 
2. 允许完全前递，绘制时空图，使用 $*$ 标注出冒险所在的位置和延迟的周期数 
3. 允许使用静态调度，尽量减少冒险数量，绘制时空图，使用 $*$ 标注出冒险所在的位置和延迟的周期数 

### 五、Cache，32 位 MIPS ，8KB 容量，一块有 32 字节，直接映射

1. 求 Cache 的总行数；画出 Cache 的结构图，标出位数，包含 $valid$, $dirty$, $tag$, $data$；求 Cache 的存储容量
2. 给你 6 个十六进制格式地址，问命中情况，写出缺失类型
3. 将 Cache 变为 2 路组相联，容量不变的情况下，画出结构图地址划分的变化；问第 2 问中 6 个地址的命中情况，比较直接映射和组相联哪一个命中率更高 
4. 多级 Cache 计算，计算 $AMAT$ 和 $CPI$，参考往年题第五章第一题

3. 多级 Cache 和 TLB 计算，需要考虑 TLB 和 Cache 的命中情况
4. 多级页表是什么；多级页表对比单级页表的优点；多级页表对比单级页表的额外开销
