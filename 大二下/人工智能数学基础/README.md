# 人工智能数学基础（大二下）

人工智能数学基础，尹翰林老师上课，无平时分无考勤，开卷考试，考多少给多少。

这门课程计算机学院和外国语学院一起上课，所以考试难度大幅降低（**最后一课**会透题，开卷考试保底 90 分）。

尹老师上课很好，手写板书（记得记笔记或者拍照，期末考试内容来自**上课板书**），教学内容包括：线性代数、矩阵分解、向量微积分、优化、概率与分布、信息论等内容。个人推荐认真听课，对数学本质感兴趣的同学可以通过网课深度学习（3b1b 等等）。

## 26 春考试回忆版（只有一道大题需要回忆）

1. KL 散度的定义，KL 散度与交叉熵、信息熵的关系，KL 散度是否满足距离三公理，KL 散度支撑集不重叠时的例子
2. 最小二乘解 or 最小范数解
3. SVD 分解 and 求伪逆
4. $f(x) = \frac{1}{2}x^T P x + q^T x + r$ 满足什么条件是凸函数
5. AdamW 的递推公式和特点
6. 方向导数是什么，梯度是什么，方向导数与梯度的关系；雅可比矩阵是什么，雅可比矩阵的几何意义；矩阵的迹的几何意义

> 尹老师**最后一课**明确说明第 1-5 题的具体题干，第 6 题关于梯度，考试开卷。第 1-5 题一题 18 分，第 6 题 3 小问 10 分。所有内容来自**上课板书**。
