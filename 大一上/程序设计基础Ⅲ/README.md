# 程序设计基础Ⅲ（大一上）

程序设计基础Ⅲ，学习C语言理论。

网课推荐B站***黑马程序员***或者***浙江大学翁恺***，可以根据教学大纲使用***AI***辅助学习。

>  编程是一门实践性很强的学科，一定要动手锻炼手速、培养手感！

复习看白皮书习题册，推荐刷***填选***，考试允许使用***CodeBlocks***和***DevC++***，大部分题目可以通过上机获得答案。

> 推荐平时使用***VSCode***、***CLion***、***PyCharm***、***IntelliJ IDEA***等等现代IDE，在此不赘述安装方式

不要速通，扎实的C语言基础有助于**后续课程**的学习，有助于**其他编程语言**的学习，更重要的是，有助于**计算机系统基础**的学习！

> 深入理解***函数***、***指针***、***结构体***
